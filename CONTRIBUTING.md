# Contributing

Brand assets require visual and product-owner review before publication.

When proposing a change:

1. Keep the icon free of text and preserve transparent padding.
2. Include all four standard sizes: 1024, 512, 256, and 128 pixels.
3. Use RGBA PNG output and verify that transparency is present.
4. Explain which product surface needs the change.
5. Do not replace an established mark with an unrelated visual direction.

For private review before opening a pull request, contact developer@windcrypto.com.
